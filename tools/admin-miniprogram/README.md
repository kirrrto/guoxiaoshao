# 果小哨独立运营工具

消费者项目的 `miniprogram/` 只包含查询、小哨、历史、我的四个页面。本目录是另一份微信开发者工具项目，不会随消费者项目上传。

## 使用

1. 在微信开发者工具中单独导入 `tools/admin-miniprogram/`，不要修改消费者项目的上传根目录。
2. 使用本项目已配置的资源方 AppID `wxc6dfebb77650f3a9` 和有该项目权限的开发者账号。云环境仍为原环境，没有新增 AppID 放行。
3. 页面先调用 `admin.stats`，服务端通过可信微信上下文验证权限后才显示数据。打开项目、改本地 `allowed` 或改 AppID 都不会授予管理员权限。
4. 操作目标用户时，输入完整消费者 `appid:openid`。资源方身份与消费者身份不同，因此工具不提供“用我的”代填。
5. 管理员名单不在 JSON 编辑器中；名单变更由云端受控配置完成。支付与兑换规则沿用后端，不因拆分而改变。

此项目连接真实数据。会员发放和次数发放使用持久幂等编号，网络结果不确定时保持相同参数重试。页面无权限或云连接失败时会清除已加载的管理数据。

此工具供项目开发与运营使用，不需要上传为消费者版本。不要将它合并回消费者 `app.json`；如需发布另一独立运营小程序，需另行处理账号和授权。

## 验证

根目录运行 `npm test`、`npm run check`、`node tools/release/check.mjs`。预览消费者页面时不会再生成管理页面；管理项目布局可使用 `node tools/ui-preview/build.mjs --admin-only --out <目录>` 离线检查，不能替代微信真机验收。
