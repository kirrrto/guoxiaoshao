## 验证范围

- 全部 2,007 项离线测试通过，无跳过。源码检查覆盖 655 个文件。会员、库存详情、授权弹窗和运营界面的浏览器回归已接入 GitHub Actions。
- 消费端离线 Chromium 实测 732 组会员、库存、提醒相关布局。四主页面另测 96 组布局、商品图与减少动态效果组合。运营端单独验证 36 组布局，其固定浅色界面在两种系统配色偏好下均受检。
- 微信开发者工具 2.02.2611132、基础库 3.17.3 实际打开查询、小哨、历史、我的，再返回查询。五次页面均就绪，路由栈深度为 1。119 张包内商品图均经 `wx.getImageInfo` 解码。四个曾被报告的页面用原生 WCC 实编译，所有声明的业务组件都有使用，编译结果均未出现 `channel-video`。
- 发布预检有 64 项本地检查通过。消费端包目录有 242 个文件，排除项为零。两份监控共享代码通过生成一致性检查，覆盖 50 个文件。本轮没有改变采样周期、覆盖范围或数据库结构。
