## 产品判断

2.0.0 围绕三个问题组织：现在能查什么，查完下一步是什么，付费后提醒是否真的就绪。优先保障已有用户的扣次、订单、权益和授权恢复，再减少从选购目标到开启关注的绕路。本轮后续按维护者明确要求调整月卡、年卡标准价及限时优惠，未以降价或抢购效果宣传代替产品体验验证。

查询、上下文开通、新品准备与激活提示均接在现有页面及真实状态机上；选购攻略作为可返回的独立小程序页面，同时连接查询、小哨、测试通知与会员入口。统计和实验默认关闭，没有数据时不推断经营原因。

开屏日历在首屏渲染后显示，默认每个发售版本每天最多一次，可不再提醒；不阻断分享配置、正在编辑的选择或库存请求，也不在发售后长期重复弹出。关闭后入口仍在查询页和「我的」。日期与取货能力分开，展示不会消耗次数或发起通知。
