# 果小哨 v3.7.3 发布说明

本版可用于体验查询和小哨的宽窗口布局。正式发布前，请用同一体验版在 Windows、macOS 微信客户端拖动实际窗口，并在手机确认原有流程。微信质检、真实收信和云端容量沿用项目的独立验收步骤。

本次消费端源码指纹为 `sha256:be285e6ec97d76c8acba1d8cfc3c34fc5c217f8aa46121196ec029adf4b3108c`，供上传后关联微信质检报告。

## 窗口与操作

- 查询页左侧选择机型、规格和门店，右侧保留最近一次查询结果。编辑时可以对照原结果，保存只更新选择，点击查询才按原规则发起请求。
- 小哨左侧列出已保存的关注，右侧显示所选商品和门店的库存、提醒状态与管理操作。窄窗口沿用纵向卡片。
- 以微信窗口的可用宽度为准。900px 起分栏，主体最多 1200px。缩回 899px 或更窄时恢复单栏。

使用示例数据的 1200px 窗口截图见[查询页](../evidence/design/3.7.3/query-desktop.png)和[小哨页](../evidence/design/3.7.3/follow-desktop.png)。

## 验证与发布

本地 2,038 项自动化测试全部通过。离线 Chromium 在 320px 至 1440px 检查双栏、抽屉和关注选择，浅色与深色共 84 项通过。配置面板另在两种主题下各通过 432 项检查，覆盖矮窗口、键盘和安全区。微信开发者工具编译通过。在基础库 3.17.3 的 430px 模拟器中，触发页面宽度变化事件后，选配器保留同一份草稿。

在体验版中拖宽和缩窄查询页，核对编辑中改过的门店仍在，取消后仍是原选择。保存后须主动查询才会产生新结果。在小哨选择第二条关注，对照商品、门店及提醒状态，刷新并拖动窗口，再核对选中项。手机另测选配抽屉、键盘和原生底栏。

本地发版检查通过 65/66 项。余下一项需要本包的微信后台复测凭据，覆盖未用组件、底栏首切闪烁、商品图体积和图片格式四项历史报告。

相对 3.7.2，云函数只有版本元数据变动。窗口缩放与切换已加载的关注均在本地完成。线上已经部署 3.7.2 业务函数的环境可以直接使用双栏，回退客户端即可恢复旧版布局。上传、微信后台复测和正式发布由维护者处理。云端和真实收信验收见 [3.7.2 发布说明](RELEASE_3.7.2.md)。
