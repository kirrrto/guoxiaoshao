# 3.9.1 退回三站点的兼容步骤

回退目标以 3.8.8 的 `69ce2fbb124b2f47253e9af8462a3d614fdaa520` 为底，保留三站点目录、取货及消费端代码，加回配置存储、已保存关注管理、按事件发生时间清理与统计，以及相应索引。原版 3.8.8 在原始配置中读到任一 `US: false` 都会在下次保存时返回 `invalid_config`。有美国关注的账号回到原版后，`market.follows` 会计入名额但看不到该条记录，取消返回 `unknown_follow`。

## 本地演练

从 3.9.1 源码运行 `node tools/release/prepare-3.8.8-rollback.mjs`。本地 Git 需包含上述 3.8.8 对象，工作区需具备生成监测包用的工具依赖，npm 缓存需包含两个旧函数锁文件所列的生产依赖。生成器在新的临时目录应用兼容修复，按两个函数各自的锁文件离线安装，并检查监测包与 API 源码一致。离线依赖缺失会阻断构建。只使用成功退出时打印的产物目录。

微信开发者工具的导入目录是产物根目录，其中包含 3.8.8 的 `project.config.json`。消费端沿用 3.8.8 版本标识。工程配置指向 `miniprogram/` 和 `cloudfunctions/`。回退时应对照这份兼容产物核验源码和函数内的 `node_modules`，原版归档与本次兼容包的版本号相同。

- 含三个 US 键的样本配置经历并发公告编辑及按新修订号关闭后，原始三张表均已移除 US。旧版配置读回日、台、港三站的原设定，运营账号仍能保存、重读一次独立公告变更。
- 用四站点 API 建立美国关注，再从三站点 API 和消费页面读取。清单保留原货号和门店，标明站点已停用，行内只提供「取消整条关注」。点按该行保留当前站点、商品和门店。会员过期后仍可直接确认取消。列表、数据库记录和账户名额索引随之更新，续费后可用释放的名额新增其他站点关注。

## 获得单独授权后执行与回读

1. 先验证生成的两个函数、旧页面和现存数据库索引具备本地演练所用版本。保留 `gxs_events.detected_at` 索引及原有索引。记录当时的两个云函数源文件、触发器、消费者版本和运行配置基线。避免在切换过程中重新打开美国站点。
2. 在支持关闭键稀疏存储的 3.9.1 API 上使用 `admin.getConfig` 获取配置和 `revision`。调用 `admin.updateConfig`，使用该 `expectedRevision`，`patch` 仅传 `{"internationalMarkets":{"US":false},"internationalMonitoring":{"US":false},"internationalNotifications":{"US":false}}`。若返回修订冲突，重新读取，按最新修订号重试这三个字段。
3. 再次 `admin.getConfig`，核对修订号和三个有效值均符合刚才的更新。只读回查 `gxs_config/runtime` 的原始文档，确认三张表均无 US 属性，日、台、港各开关和其余业务字段与最新写前快照一致。配置正常变化的元数据为 `configRevision`、`updatedAt` 和 `updatedBy`。3.9.1 的 `getConfig` 会补出默认值，单看三个 `false` 无法判断原始文档能否被旧版保存。若基线或修订号期间变化，重新核对并发修改。
4. 使用本地脚本生成的兼容 `gxs_api` 与 `gxs_monitor` 替换待回退函数。待新实例生效、在途调用结束后，回读比对函数源文件与各自生成目录，核对定时器和版本。再读 `market.catalog` 确认只列 JP、TW、HK，`admin.getConfig` 三张表只含三站，修订号与原始配置匹配。刷新运营页面，依下一次已授权的配置调整验证预期字段、修订号和审计记录。旧的在途编辑有冲突时应重新载入。
5. 需要回退消费端时使用配套三站点客户端。待单独授权后用受控测试账号确认已有美国关注在列表中可见、可取消，且取消后可复用名额。回退无需批量改写或删除关注。今后恢复四站点时，先部署匹配的四站点函数，缺省 US 开关均关闭，仍保留的关注沿用原有归属及状态。

若起点仍是 3.9.0，先在其 API 上按修订号关闭三个开关并回读有效值。该版本会把 `US: false` 存入原始文档。在三站点兼容函数生效后，重新读取修订号，通过兼容 API 显式重发步骤 2 的三个关闭字段，再完成步骤 3 和 4 的原始配置与三站点回读。离线测试覆盖了这个中途状态。若已切至原版 3.8.8 并遇到 `invalid_config`，先恢复兼容 API，再按相同步骤处理。

本次只运行本地演练。以上云端、索引、触发器、管理员保存与真机验证属于获授权后的操作。
