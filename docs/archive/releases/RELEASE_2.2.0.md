# 果小哨 v2.2.0 发布说明

候选日期：2026-10-14（北京时间）。维护者要求本批以 **v2.2.0** 发版并同步 GitHub。状态：**源码与版本元数据已同步；未部署云函数、未上传微信版本、未提审或正式发布**。承接 v2.1.1 及 2026-10-14 商品目录扩展。

## 面向用户的更新小结

可选商品新增 HomePod mini 2 五种颜色；iPhone Duo 的容量与配色已全部开放。保存选择后返回再进入，配置与门店可正确恢复。

## 本版变化

- **HomePod mini 2 进入可选配置**：白色、粉色、蓝色、绿色、午夜色共 5 个 SKU，可按颜色选择并保存；与旧款 HomePod / HomePod mini 并存，无重复项。
- **iPhone Duo 8 个配置开放**：夜空色／星光白色 × 256GB／512GB／1TB／2TB 均可保存选择。预购阶段仍可先保存，取货查询与关注按服务端校验放行。
- **目录展示与保存链路**：产品选择页按发售日期优先展示新款；颜色与容量映射来自官方配置维度，保存后重进、重新编译可恢复同一 SKU 与门店。

## 保留的业务规则

查询计次、关注与微信提醒仍为会员专属；免费用户可浏览目录并保存选择。周／月／年卡价格、支付与退款规则未改。目录数据以服务端校验为准，保存选择不等于开放取货查询。

## 发布前仍需人工操作

1. 微信开发者工具打开本项目 → 清缓存并重新编译 → 产品选择页确认 HomePod mini 2 出现在 HomePod 分组且 5 色可选。
2. 选择某一颜色与门店 →「保存选择」→ 返回首页再进入查询页 → 确认 SKU 与门店保留；再「编译」或重启小程序复核一次。
3. 回归：iPhone 18 Pro / Duo 任一配置的保存、恢复、查询入口不受影响；控制台无新增报错。
4. 真机（iOS / Android）重复步骤 2–3；模拟器通过**不能**代替真机结论。
5. 按既有流程部署 `cloudbase_auth` / `gxs_api` / `gxs_monitor`（本版业务规则未改，仍须与线上版本一致性核对），再上传 v2.2.0 前端并提审。
