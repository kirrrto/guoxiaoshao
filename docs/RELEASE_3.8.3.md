# 果小哨 v3.8.3 发布说明

指定测试账号可在日本、台湾和香港站点公开前手动查询门店库存。生效需要部署本版 `gxs_api`，并使用配套消费端。微信体验版、真机和后台质检仍待维护者复测。

本次消费端源码指纹为 `sha256:2eba72d3e119732e087105fd2994de5d8ecea5b357dc8cdeac8a3fbb00400a44`，供上传后关联微信质检报告。

## 修复与用量

3.8.2 已给指定管理员免扣查询次数，但「其他站点」页面和云函数仍只读取公开查询开关。现在登录后的账号信息另行给出可测试的站点，公开目录仍可共用。服务端在查询事务及上游请求准入时复核测试账号绑定和管理员名单。切换账号会清除旧的测试资格和页面结果。

每次新测试查询向所选站点请求一个货号、一家门店，计入现有的账号和站点限流、上游预算与熔断。结果写入本人的查询回执，相同请求编号可重读。测试样本独立于共享库存、事件和通知，避免其他人从旧关注或通知详情读到测试结果。公开查询、自动监测、订阅通知的三个开关仍分别控制原有服务。

查询中途断线后，即使站点转为公开，恢复的测试查询也只更新本人的回执。如果之前的普通查询已扣次，恢复时站点已关闭，系统退回原扣次数。
