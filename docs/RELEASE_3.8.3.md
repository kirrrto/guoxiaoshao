# 果小哨 v3.8.3 发布说明

有效月卡和年卡可手动查询日本、台湾和香港的门店库存，免扣查询次数，无需先关注。各站的公众查询开关可以保持关闭。上线前需部署本版 API，并上传配套消费端，在体验版用普通月卡或年卡核对查询结果和余额。地区自动监测与微信收信需要单独启用和验收。

本次消费端源码指纹为 `sha256:7861e5985d24572d82eeca7ded99e72539632a23b6f3e1af1781dafd071bab2c`，供上传后关联微信质检报告。

## 客户体验

- 按北京时间每日签到可领 1 次查询，最多攒 10 次。余额已满时，可先用掉一次，再于当天签到。「次数明细」默认收起，用户展开时才读取记录。新浏览和新历史查询已停止发放奖励。此前已取得且当天仍有效的奖励可领一次，已有余额和查询退款保留。
- 在「其他站点」选好受支持的商品和门店后，月卡、年卡可立即查询，也可保存关注。月卡最多保存 4 个配置，每个最多选 4 家门店。年卡最多 5 个配置，每个最多 5 家门店。大陆及其他站点共用配置名额。站点开启公众查询后，有效周卡可查询新品，免费账号在当地上市满 30 天后可用签到次数查询。站点尚未开启监测时，关注页面会显示实际状态。
- 空关注列表及全部暂停的列表停止定时读取库存。自动采集在请求前逐项确认是否仍有有效关注，多人关注同一目标可共用一次采样。用户主动点「查询」仍可查未关注的货号。取消关注时，已通过资格检查的那次请求仍可能完成。

## 部署与回退

1. 更新 `gxs_api` 并上传与本包指纹匹配的消费端。普通月卡、年卡查询三站无需修改运营开关。监测函数包使用同一套上游请求保护代码，可随 API 同步部署。回读函数代码并核对消费者源码指纹，以区分同号构建。
2. `internationalMarkets` 控制其余账号的公众查询。需要上线自动提醒时，在独立运营工具「运行配置」按站点启用 `internationalMonitoring`。看到该站实际自动采样后，再启用 `internationalNotifications`，核对相应语言的到货模板、发送器和用户订阅授权。
3. 微信体验版使用普通月卡或年卡，在未关注目标的情况下分别点日本、台湾、香港的查询按钮，核对门店、观测时间及免扣次数。核对签到、明细、关注保存和取消。若提供微信通知，验证真机收信和回跳。微信后台按本包指纹完成质检复测，之后由维护者提审和发布。
4. 本版沿用现有的关注记录、共享名额、查询账本和采集预算，无需数据迁移。采集准入会读取有效关注和账号资格。空列表、资格读取失败或所有目标均退出时跳过苹果接口。若需暂停，可按站点关闭监测或提醒，已保存记录保留。
5. 若配套回退到同号候选 `de7819c`，关闭公众查询的站点会再次拒绝普通月卡、年卡的手动查询。回退这项查询改动无需修改监测开关，也无需撤销已入账的签到或退款。
