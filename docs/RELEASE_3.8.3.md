# 果小哨 v3.8.3 发布说明

在「我的」可直接看到可用次数、每日签到入口和 10 次上限，点一次「次数明细」即可核对扣次和退款。有效月卡、年卡可直接保存日本、台湾和香港的门店关注。上线前需更新本版 API，在微信体验版核对签到、明细和本包质检。要开放地区提醒，还需验证该站的自动采样和真机收信。

本次消费端源码指纹为 `sha256:6b3ce3861d03fea83f8d41edc394bd2cce46d2e753eb81d54c9d76b82739bb01`，供上传后关联微信质检报告。

## 客户体验

- 按北京时间每日签到可领 1 次查询，最多攒 10 次。余额已满时，可先用掉一次，再于当天签到。「次数明细」默认收起，用户展开时才读取记录。新浏览和新历史查询已停止发放奖励。此前已取得且当天仍有效的奖励可领一次，已有余额和查询退款保留。
- 在「其他站点」选好受支持的商品和门店就能保存关注。月卡最多保存 4 个配置，每个最多选 4 家门店。年卡最多 5 个配置，每个最多 5 家门店。大陆及其他站点共用配置名额。周卡仍可查询新品。站点尚未开启监测时，页面会显示真实状态。
- 空关注列表及全部暂停的列表停止定时读取库存。自动采集在请求前逐项确认是否仍有有效关注，多人关注同一目标可共用一次采样。用户主动点「查询」仍可查未关注的货号。取消关注时，已通过资格检查的那次请求仍可能完成。

- 本包全量自动化测试 2,180 项全部通过，无跳过。源码、英文词条、监测函数共享文件一致性检查通过。发布检查 65/66 项通过，剩余一项为微信后台对上述指纹的质检复测证据。

- 首次打开「我的」或从提醒测试跳回签到卡，账本请求均为 0。点开明细才发起读取，连续点开、收起可复用同一次读取。离开页面会收起账本。已验证加载失败原地重试、签到后更新、切换账户清空旧记录，以及在途回复不会把旧记录写回。

## 部署与回退

1. 更新 `gxs_api` 以启用本次账本读取的账户校验。`gxs_monitor` 已含本版逻辑，若要统一云端版本显示，可同步部署。核对函数实际代码、每分钟定时器以及消费端指纹。
2. 需要上线区域提醒时，在独立运营工具「运行配置」按站点启用 `internationalMonitoring`。看到该站实际自动采样后，再启用 `internationalNotifications`，核对相应语言的到货模板、发送器和用户订阅授权。`internationalMarkets` 单独控制普通用户手动查询。
3. 微信体验版用真实账号核对签到、次数明细、关注的保存和取消，并验证到货通知实际收信及回跳。微信后台按本包指纹复测闲置组件、首次切换 tab、商品图片大小和图片格式，之后由维护者提审和发布。
4. 本版沿用现有的关注记录、共享名额、查询账本和采集预算，无需数据迁移。采集准入会读取有效关注和账号资格。空列表、资格读取失败或所有目标均退出时跳过苹果接口。若需暂停，可按站点关闭监测或提醒，已保存记录保留。
5. 如需回退，先关闭受影响站点的采集，再按已备份的构建配套回退函数和消费端。旧监测版本缺少发出请求前的关注复核，旧 API 会恢复浏览奖励，并限制用户在已关闭的站点保存关注。已入账的签到和退款无需回滚。
