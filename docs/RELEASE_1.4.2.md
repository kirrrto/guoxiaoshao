# 果小哨 v1.4.2 发布说明

日期：2026-09-28。紧急修复版，基于 v1.4.1。本版调整会员页兑换入口展示，降低对虚拟支付主路径的干扰；不改变 7 元／7 天会员商品、支付权益规则。

## 用户可见

- 「兑换码开通」从会员主按钮区移至底部列表，与「使用说明」等同级，不再高亮。
- 付费购买主按钮保持「立即开通／续费会员」优先。

门店显示修正（2026-09-30）：官网以城市命名的四家门店补充所在商场，页面显示为「武汉武商 MALL」「苏州中心商场」「昆明顺城购物中心」「长沙国金中心」。地址分别核对 [武汉](https://www.apple.com.cn/retail/wuhan/)、[苏州](https://www.apple.com.cn/retail/suzhou/)、[昆明](https://www.apple.com.cn/retail/kunming/)、[长沙](https://www.apple.com.cn/retail/changsha/) 官网门店页。门店选择、查询结果、关注、历史和提醒记录使用同一显示规则，兼容旧目录缓存与已保存记录；商场名称和地址也可用于搜索。此项为前端显示修正，需要上传并发布更新后的前端包。
