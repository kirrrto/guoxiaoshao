# 果小哨 v3.0.1 发布说明

2026-10-16（北京时间）。状态：**本地候选，未部署云函数、未上传微信版本、未提审或正式发布**。承接已发布的 v3.0.0，只处理微信云测未通过项。云函数业务代码未改，线上继续使用已发布的 3.0.0 服务端。

## 用户可见变化

页面打开更顺，页眉图标更小。输入时底部导航会让开。离开当前页面后，键盘不再挡住操作。

## 对应的云测项

- 查询页页眉图标从约 22.45KB 压到约 6.5KB，低于内联图片 10KB 的未通过线。原图仍保存在品牌资料中。
- 「我的」页启动不再调用同步存储。授权记录、待确认订单和上次选择改为异步读取，恢复结果不变。
- 我的页和小哨页的配置弹层、提醒授权改为用时注入，打开时才加载。基础库注入的 `channel-video` 改为用时注入且页面不渲染。
- 云环境初始化拆成多次短任务，避免单次脚本执行过长。
- 自定义底栏和配置弹层在页面隐藏时解除键盘高度监听。从底部页面进入攻略时，不再把未解除的监听留在攻略页。

价格、会员、支付、提醒次数、免打扰和查询计次规则都没有改。

## 不部署云函数

本地版本号已与 3.0.1 对齐，便于发布检查把整份源码看成同一版本。这不表示需要重新部署 `cloudbase_auth`、`gxs_api` 或 `gxs_monitor`。未获另行授权前，不要用这次版本号覆盖线上 3.0.0 云函数。

## 发布前仍须完成

1. 微信开发者工具上传 v3.0.1 前端，记下代码包大小和版本号。
2. 体验版核对：查询页页眉图标、我的页打开、配置弹层与补充提醒次数、从查询进入攻略后返回。输入时底栏让开；授权、待确认订单和上次选择仍能恢复。
3. 用同一套云测再跑上次未通过的五项。通过后再提审。
4. 源码经 `_github` 同步并标记 `v3.0.1`。根目录本身没有 Git 元数据。
