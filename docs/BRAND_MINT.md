# 果小哨 · 微信绿主题与轻质感图标

更新日期：2026-09-16。业务版本 1.1.1，构建标识 `mint-glass-brand`。

## 设计依据

本次以用户提供的微信绿色样本、绿色圆角图标和悬浮玻璃导航截图为视觉参考。Logo 保留果小哨自己的“口哨 + 叶片 + 两条声音线”，不使用微信聊天气泡标识。最终图标采用白色主体、绿色圆角底、轻微上缘高光和下缘厚度，避免厚重的透明雕塑效果。

## 颜色

- 品牌主绿：`#00C375`，对应用户样本中绿色区域的 RGB(0, 195, 117)。按钮、选中图标、开关使用这个色相。
- 小字与链接：`#007A49`；主按钮文字：`#073C2C`。在鲜绿色上使用深色文字，兼顾可读性。
- 背景：浅薄荷色；错误和警告保留红色、黄色语义。
- 未选中导航标签：`#5D6F66`；选中标签：`#007A49`。

## Logo 资源与来源

Logo 使用内置图像生成工具，根据用户提供的微信图标材质参考和前一版白色口哨轮廓生成。生成后的原始 PNG 原样保留，仅用 `tools/assets/prepare-logo.mjs` 进行尺寸缩放和无损 PNG 压缩，未使用代码重绘图形。

- `docs/brand/logo-mint-master.png`：1254 × 1254 原图。
- `docs/brand/logo-mint-512.png`：512 × 512 平台备用文件。
- `miniprogram/images/brand/logo-mint-144.png`：144 × 144，“我的”页面实际使用，约 23 KB。
- `docs/brand/logo-manifest.json`：尺寸、字节数和 SHA-256 校验。

图像为不透明 RGB PNG，圆角外为浅薄荷底色；没有把棋盘格当作透明背景。平台头像尚未在公众平台替换，工程内的 Logo 已接入。

最终生成提示词见 [Logo 生成记录](brand/logo-generation.md)。

## 导航玻璃

中央使用 5.5% 白色底层，不对整条胶囊做背景模糊。左右各 36px 的边缘层使用渐变遮罩和局部磨砂；支持不足时保留通透高光，不退回厚白底。导航图标和文字保持清晰，最后一项页面内容可滚动到导航上方。

这是小程序 CSS 对参考图的视觉近似。图标与文字自身仍会占据视觉区域，不宣称所有重叠文字都可完整阅读，也不宣称系统级折射效果。完整规格见 [悬浮玻璃导航](FLOATING_GLASS_NAVIGATION.md)。

## 验证范围

最终文件验证记录位于 `evidence/verification/1.1.1-mint-glass/`：

- 90 个离线页面场景：横向溢出、文字裁切、缺字、图片失败均为 0。
- 306 个导航布局组合：全部通过，覆盖 320/375/430px、100%/130% 字号和模拟安全区域。
- 9 组玻璃光学检查：全部通过。中央细线对比度保留约 94.51%，边缘按渐变虚化；装饰层不阻挡按钮点击。
- 82 处重点文字控件：没有对比度不足。主按钮最低 5.71:1，选中导航最低 4.53:1，未选中导航最低 4.72:1。此检查不代表整屏无障碍认证。
- Logo 的 36/48/60/144px 缩小效果人工查看通过。
- 官方编译器：7 份 WXML、9 份 WXSS 全部通过，编译前后源文件哈希一致。
- 微信开发者工具 Stable 2.02.2608070、基础库 3.17.3、iPhone 15 Pro 模拟器：重新编译后新 Logo 正常加载；四个入口实际点击可切换且选中项对应页面；查询页与个人中心滚动结束后末尾内容完整位于导航上方。截图与说明见同目录的 `native/` 与 `native-verification.md`。
- 本地发布预检 22 项通过，前端资源存在、导航路由一致、验收页面与模拟运行模块未进入前端。前端源文件合计 537,790 字节，不等于微信实际上传包大小。

离线结果是实际 WXML/WXSS 的 Chromium 近似渲染；微信开发者工具模拟器与 iOS/Android 手机仍属于不同验收环境。手机效果需要实际设备验收。
