# 果小哨 · 悬浮玻璃导航

## 设计与参考图的关系

本次参考用户截图红框中的底部导航：整条导航从页面底部浮起，外轮廓为大圆角胶囊，中间通透、两侧弧形边缘有逐渐淡出的磨砂与高光，当前入口有独立的半透明椭圆底色。实现使用果小哨的新薄荷绿与口哨品牌图标。

导航入口固定为 **查询、小哨、历史、我的**，对应既有四个页面。选中态由实际显示的页面决定。管理后台不在导航入口中。

## 布局规格

- 胶囊高度 66px，左右距离屏幕边缘各 12px，最大宽度 520px，宽屏居中。
- 胶囊底部距离为 8px 加设备安全区域，避开手机底部手势区域。
- 每个入口等宽，触控区域高度 54px；图标为 25px，标签为 12px。
- 胶囊中间使用不透明度 5.5% 的白色底层，不对整条导航施加模糊；两端分别用 36px 的光学装饰层表现弧形边缘。
- 选中项使用不透明度 10% 的灰绿色椭圆，不施加模糊；文字使用深绿 `#007A49`，图标使用品牌绿。未选中标签使用灰绿 `#5D6F66`，保持浅色内容背景上的辨识度。
- 四个主页面底部增加 98px 加设备安全区域的空间，使最后一项操作能够完整滚动到导航上方。

## 兼容与性能

组件使用小程序原生自定义 `tabBar`，在 `app.json` 中开启 `custom`。组件样式隔离，避免页面按钮样式影响底栏布局。

### 当前版本：清晰中央与局部磨砂边缘

用户补充的滚动截图明确要求中间可以透出下方字形。本轮取消整个胶囊的 `backdrop-filter`，中央区域仅叠加 5.5% 白底；文字与图标保持正常不透明度。左右各 36px 的 `.floating-tab-edge` 在浏览器同时支持遮罩和背景模糊时，使用 7px 模糊及 108% 饱和度，并通过从外缘不透明到内侧透明的渐变遮罩逐渐减弱效果。模糊区域不延伸到中央。组件没有持续动画或全屏滤镜。

不支持遮罩或背景模糊的环境使用相同的通透底层，只保留两端的渐变高光、细边线和轻阴影，不退回厚白底。两端装饰层均设置 `aria-hidden="true"`、`pointer-events: none`，按钮位于它们上方。此实现为小程序内的 CSS 视觉近似，不宣称实现系统级液态玻璃光学折射。

选中项用浅灰绿色 10% 的底色，不再叠加整块高光，也不使用背景模糊。可透出下方内容并不意味着导航图标下方的所有文字都能完整阅读：图标和标签本身仍会占据视觉区域，页面底部留白继续保证最后一项能够移到导航上方阅读和操作。

### 前版通透度微调说明（保留追溯）

上一版将不支持模糊时的底层不透明度设为 52%，支持模糊时设为 22%，整条导航使用 8px 模糊及 115% 饱和度；选中项底层为 14%。用户后续指出中间字形仍被磨糊，因此这些值已被上面的分层方案取代，不是当前设计规格。

底部安全区域同时提供常规值、旧版 `constant()` 与 `env()` 声明。导航层级为 90，现有原生型号/容量选择器与微信弹窗显示在导航之上。

## 交互策略

1. `utils/tab-bar.js` 集中维护四个页面的路由、名称与图标。
2. 每个主页面的 `onShow` 在加载数据和早退条件之前同步选中项。查询页关注按钮等代码触发的页面切换，也会正确更新导航。
3. 点击通过 `wx.switchTab` 切换。导航不会在切换成功之前提前把目标页标成选中。
4. 共用的切换锁限制未完成的重复切换；完成或失败仅释放对应请求的锁。
5. 切换失败时保留实际页面状态，显示“页面切换未完成，请重试”，允许重新操作。
6. 键盘弹出时隐藏导航，避免遮挡城市搜索或兑换码输入。页面隐藏后忽略键盘事件，组件卸载时注销监听；返回页面时重新同步状态。

## 修改范围与更新方式

悬浮导航初次改版修改了前端导航组件、四个主页面的导航接入及底部留白。本轮分层玻璃修改组件 WXML 和 WXSS，新增两端装饰层；同轮品牌更新调整了主题和图标。布局尺寸、54px 触控区域、页面留白、导航路由与点击逻辑保持不变；没有修改会员、次数、支付、库存采集或消息发送逻辑。

无需重新部署云函数。使用当前工程在微信开发者工具中重新编译、预览，上传前端新版本后，用户才能看到新的底部导航。

## 当前版本分层玻璃验证

- 离线光学检查通过 9 组：320/375/430px 宽度分别检查正常支持、无背景模糊、无遮罩三个场景。真实组件中央不存在背景模糊或其他滤镜，两端装饰层为 36px，四个按钮仍能直接命中。
- 用黑白 1px 细线作对照，中央对比度保留约 94.51%；正常支持时两端对比度约 35.45%–35.82%，验证模糊只集中在边缘。回退场景两端仍通透，不变为厚白面板。光学采样时临时隐藏了按钮以单独测量背景层，文字截图与命中检查时按钮正常显示。
- 方法与完整结果见 `evidence/verification/1.1.1-mint-glass/optics.json`。这是 Chromium 对实际 WXML/WXSS 的近似预览，不是微信真机验收，也不测量系统级折射、透镜形变或手机 GPU 的具体渲染效果。
