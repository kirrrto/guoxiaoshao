# 果小哨 v2.1.1 发布说明

候选日期：2026-10-13（北京时间）。维护者确认本批改动使用 **v2.1.1**，承接 v2.1.0 及支付合规整改。状态：**源码与版本元数据已同步；未部署云函数、未上传微信版本、未提审或正式发布**。

## 面向用户的更新小结

会员购买暂不可用时，不再展示价格与开通入口。仅展示当前可购买的套餐，续费与升级同样遵守。已有会员权益、购买记录与兑换不受影响。

## 本版变化

- **支付不可用隐藏交易入口**：无任何可购买套餐时，「我的」不再渲染套餐价格、划线价、促销标签、「立即开通／续费／升级」等入口，改为中性提示「会员购买暂不可用，现有会员权益不受影响。」
- **按套餐判断可购状态**：周卡／月卡／年卡分别按服务端 `enabled`／`paymentReady` 与设备支付能力判断；部分不可用时只展示可购套餐，全部不可用时隐藏购买区。
- **待确认订单不自动改套餐**：存在未确认订单时保持原订单套餐与金额，不自动切换到其他套餐；订单查询、继续支付、放弃与历史记录恢复仍可用。
- **收紧收银台调起条件**：删除待确认订单强行放行购买就绪的分支；平台／全局支付暂停时不再调起 `wx.requestVirtualPayment`。设备 API 存在不等于商户收款权限正常。

## 保留的业务规则

- 仍使用微信官方虚拟支付 `wx.requestVirtualPayment`（道具直购 `short_series_goods`），签名下单、查单、发货推送、退款、定时对账与历史 v1–v4 订单快照逻辑未改。
- 价格口径不变：周卡 700 分、月卡 1499 分、年卡 12900 分（实付）；划线价 30／360 元仅界面展示。详见 [支付配置说明](VIRTUAL_PAYMENT_SETUP.md)。
- 兑换码、会员权益顺延、购买记录、微信提醒与关注配置不受本版影响。
