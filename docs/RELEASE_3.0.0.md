## 用户可见变化

免打扰可设置多个时段，支持夜间、午休快捷添加。补充提醒次数直接唤起微信授权，结果在原页反馈。查询重点更靠前，关注和历史更紧凑，原任务可继续。

## 实施取舍

- 项目书与效果图作为参考，沿用现有主题绿、四个底部入口和真实业务能力。没有照搬虚构日期、商品图片或业务状态。
- 免打扰支持 1–8 个时段，按北京时间每天生效，支持夜间/午休快捷添加及恢复时间提示；跨午夜、重叠、全天均有明确展示。保存成功后才更新页面，旧单段设置继续可读；旧客户端不得覆盖新用户的多段设置。
- 小哨使用紧凑关注卡片，先展示配置、门店数量、提醒状态和最近观测；门店明细及管理操作在同页展开。“我的”集中呈现会员、提醒中心及查询与体验次数。
- “我的”和小哨点击“补充提醒次数”直接进入微信原生授权，满足账户、会员及模板条件时不再先打开授权面板。授权结果在原页反馈，已同步和待同步数量分别显示；“重试同步”沿用原请求，不重复申请微信授权。
- 会员套餐与规则按需展开，保留服务端价格、实际名额、退款/续费说明、购买记录和原订单核实路径。
- 查询选择保留仍有效的规格与门店；主动切换型号等选项直接生成有效草稿，在面板底部一次保存，不再额外确认配置。目录被动刷新导致已存 SKU 失效时仍需重选，取消编辑保留原目标。结果主操作位于门店列表之前，新鲜可取货门店优先呈现；未知、过期及观测时间仍明确保留。
- 备选门店可切换全目录城市，跨城已选门店保留为可移除标签；切换和勾选不扣次，主动点击查询才按原规则计次。近期记录仍按原附近范围读取，所选门店超出范围时整次不读，也不悄悄过滤门店；后端范围规则未改。
- 历史以紧凑条件区和供应事件时间轴呈现，保留成本、余额和观测覆盖限制，不改成个人查询记录。下单指南、历史条件与测试签到回程保留原目标或原请求，不自动重复查询、扣次或发送。
- 既有 `resultNextAction` 等产品开关保持原配置；本轮没有新增旅程采集事件、提高采集频率或宣称转化与性能提升。

详细需求对应、兼容规则与交接见 [V3_IMPLEMENTATION_2026-10-15.md](V3_IMPLEMENTATION_2026-10-15.md)。

## 本轮指南入口、保存流程与跨城选择

查询页的“发售日历与选购攻略”放在品牌标题后、配置选择前。主动进入后先看到海报，下滑就是已展开的攻略；从“我的 → 使用攻略与常见问题”进入则直接显示攻略，不显示海报。日期与商品事实沿用原来源，不自动弹窗，整月日历网格仍可按需展开。

选择器去掉“确认此配置”“配置待确认”及相应保存限制。主动切换类别、系列、型号、容量或颜色时，保留仍有效的选项，直接形成当前可选组合的草稿，最后只需点击底部保存；取消不替换原查询或关注目标。目录被动刷新使原 SKU 失效的保护仍保留，需要重新选择有效配置。

备选门店支持在全目录城市间选择并发起明确查询，跨城已选标签不会因切换城市丢失，可单独移除；账号门店数上限及查询计次规则保留。读取近期记录仍限原附近范围，超范围时整次不读取，不把所选门店静默缩减为可读子集。

“我的”中“体验微信提醒”入口下的独立重复说明已删除，测试通知页面发送前的授权、计次及非真实放货说明继续保留，发送逻辑未改。
