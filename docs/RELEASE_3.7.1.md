# 果小哨 v3.7.1 发布说明

**可以上传 3.7.1 体验版。** 正式发布前，还要用这个包完成微信质检、确认手机能收到提醒，并在隔离环境检验后端能否承受 300 人同时查询。3.7.1 包含 3.7.0 开发包上传后的修复，于 2026-11-20 整理。维护者手动部署云函数并操作微信发布。

本次消费端源码指纹为 `sha256:79999056b37e11ffc5858470652f7159d5299a9fea7d1a5b64138020164fa4f4`，供上传后关联微信质检报告。

## 微信更新说明

- 查询遇到异常时，点「刷新状态」不扣查询次数。小哨会提示最近一次检查失败，有上次结果时也会标出当时的时间。
- 名字相同的到期事项也可以分别开启微信提醒。小屏上的提醒按钮更容易点，取货攻略切换阶段时能看到对应步骤。
- 周卡和月卡使用绿灰卡面，年卡使用暖金点缀，均保留会员果哨标志。

## 维护者发布步骤

1. 用本版锁定依赖部署 `gxs_api` 和 `gxs_monitor`。下载云端运行包，与本版文件核对，并在日志中确认定时任务自行触发。果小哨与「撞词儿」共用的鉴权沿用现有授权。
2. 在微信开发者工具导入仓库根目录，上传消费端时填写 **3.7.1**。在公众平台选中这次上传的体验版，核对「我的 → 更新公告」第一条为 3.7.1。
3. 对这个体验版运行微信云测，检查未使用组件、底栏首次切换、商品图大小和图片格式。保存任务号、设备、基础库版本和报告，填写[质检登记表](../config/wechat-quality-findings.json)。
4. 用 iOS 和 Android 打开同一个体验版，检查冷启动切页、商品图和断网后的恢复。用测试账号在「我的 → 通知与免打扰 → 体验微信提醒」发一条测试消息（使用 1 次查询次数），再打开微信「服务通知」确认收到。若开放购买，核对真实支付和权益到账。
5. 在隔离环境验收 300 人同时查询与采样时效。11 月 19–20 日的本地模拟按每分钟 600 次采集计算。300 人同时查询 900 个不同目标，172 人获得完整结果，1 人获得部分结果，127 人没有取得结果。[容量验收目标](../config/delivery-targets.json)

升版前的功能与界面验证见[代码审查记录](../evidence/verification/3.7.0/code-review-20261119.md)。本次沿用现有数据库结构。需要回退时使用此前保存并核验的客户端及业务云函数包。
