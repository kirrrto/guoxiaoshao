# 果小哨 v3.9.1 发布说明

本地修订候选已修复门店跨日历史、新品免费查询和选店交互。正式发布仍需完成候选云函数与索引核验、微信同包质检、真机手势和订阅消息收信，以及隔离环境容量与库存时效验收。

本次消费端源码指纹为 `sha256:d0058463249ac5a97da1eb52d1e1490b7b438251ab12e238af486eec642a0353`，供微信后台质检关联本包。

## 本版修复

- 门店观测仍按当地日期归档。短期事件按实际检测时间清理，运营滚动统计在读取上限内按检测时间取数。特拉华和夏威夷的同一款新品分别在各自当地开放日零点允许免费账号使用签到次数查询。
- 三站点兼容回退时，运营配置可继续保存。「其他站点」里的旧美国关注显示停用，保留原货号、门店和整条取消入口。取消后可复用与大陆共用的名额。
- 在美国站重复确认同一州会保留门店和查询回执。下拉被系统取消时抽屉回弹并保留草稿。提醒语言根据该条关注所属站点的发送条件显示和保存。
- 美国目录刷新会比对逐系列的既有零售货号。漏掉旧货号时报告系列与货号，并保留上次核准的目录。并发刷新在替换文件前互斥，防止另一批刚新增的货号丢失。
- 目录按本地源文件和随包运行目录核对。美国有 269 店、44 个州及哥伦比亚特区、7 个门店时区、24 个系列、357 个零售货号，其中 347 个以 `LL/A` 结尾，10 个以 `AM/A` 结尾。俄勒冈、特拉华、新罕布什尔、阿拉斯加分别有 3、1、3、1 家店。日本、台湾、香港各有 24 个系列、348 个零售货号，门店数分别为 11、2、6。

## 兼容回退与用量

从 3.9.1 回到三站时，先按修订号关闭三个美国开关并回读原始文档，确认仅移除了三个 `US` 键。使用由 3.8.8 源码生成、保留时间窗口和已存关注移除功能的兼容包。已有关注由用户自行决定是否取消，无需批量迁移。已被旧版清理的事件无法由此补丁恢复。[兼容回退与回读演练](ROLLBACK_3.9.1_US.md)

按 `detectedAt` 过滤沿用既有查询次数、读取上限和清理计划，新增单字段索引会占用索引存储并随事件写入维护。门店日期、同州选择、手势与语言判断直接使用已加载数据。目录防覆盖只发生在本地维护工具。实际云账单和上游响应时效仍待有授权的环境测量。
