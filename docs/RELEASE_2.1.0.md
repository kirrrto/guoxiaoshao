# 果小哨 v2.1.0 发布说明

候选日期：2026-10-13（北京时间）。维护者确认本批改动使用 **v2.1.0**，承接原 v2.0.1 候选及本轮界面优化。状态：**源码同步至 GitHub 并标记 `v2.1.0`；未部署云函数、未上传微信版本、未提审或正式发布**。

## 面向用户的更新小结

会员标识更醒目，套餐与权益展示更清晰。会员区可体验微信提醒，发送结果与收信反馈更直观。开屏日历和选购指南更清楚，我的可联系客服；待确认订单不再卡住。

## 本版变化

- **会员身份更清楚**：Logo 放大为 56px，已开通会员使用金色徽章与淡金卡片；免费、已到期分别显示独立身份标识。保留剩余时长、有效期、实际关注名额和购买记录。
- **套餐与账户布局优化**：套餐全宽显示，操作统一为「延长会员」「升级套餐」。微信提醒体验入口移至会员区域，常用入口补充对应图标；详细权益与购买规则按组展开。
- **微信提醒体验页重构**：结果与收信反馈优先展示，首次发送、继续原请求、再次体验分别呈现。扣次说明保留在操作旁，详细规则和未收到排查可展开；微信受理仍不等于送达。
- **持续执行当前价格**：月卡 14.99 元、年卡 129 元，取消原定到期恢复标准价；标签改为「优惠价」，删除截止后涨价描述。参考价为 30／360 元，不代表当前收款金额。此项目前仅在本地候选中实现。
- **待确认支付可恢复**：查单失败时仍可放弃原订单，迟到付款仍会开通；金额矛盾或支付中仍禁止放弃。保留继续支付入口和超时复位，付款主按钮位于套餐下方。
- **界面与交互整理**：改进查询、关注、历史与攻略页的文本层次、图标和浮动导航，并检查窄屏、宽屏、深色和放大字体下的布局。

## 发版前复核与界面整理（2026-10-13）

- 付款按钮下方恢复显示「虚拟服务一经售出不予退款」，与「不自动续费，付款确认后生效」分为两段，窄屏按句换行，不在词中断开。
- 更新公告中 2.1.0 与 2.0.0 的日期标签由「候选更新」改为「更新记录」，与其他版本一致；公告正文不变。
- 价格展示经维护者确认保持现状。复核提示：历史 v2 订单中月／年卡实收 19.90／200 元，30／360 元参考价从未实际收取；如需降低价格标示风险，可改为日均价对比。
- 「我的」：「小哨提醒」与「小哨提醒记录」合为一张卡，两行入口直接显示当前通知设置和已显示的记录数；清空按钮移入展开后的记录说明旁。签到完成后显示「今日已签到」状态标签，不再是灰色的不可点按钮。
- 查询页：发售日历入口改为常规卡片，副标题按发售阶段显示（开启预购、正式发售、已发售），窗口结束后回到通用说明，不再写死机型。未选配置时只保留「想查哪一款？」一个标题。关注列表不再逐条重复「以官网实际取货为准」，改为卡片底部说明一次。
- 「暂无供应」在查询结果、关注列表和历史最近观测中与小哨页一致，使用中性色；「可取货」仍为绿色，过期和待确认仍单独提示。
- 选配置弹窗的产品类别改为换行排列，所有类别同屏可见（离线目录共 6 类，HomePod 原先需横向滑动才能看到）。深色模式下线性图标提亮到深色主题的绿色。
- 开屏海报改为当前阶段与预购／发售两个日期块，弹层内不再铺整月日历；完整月历在选购指南中按需展开。选购四步改为同卡步骤条，常见问题与帮助入口分组。
- 「我的」、选购指南和待确认付款面板提供微信原生客服会话（`open-type="contact"`），不跳出小程序、不复制官网链接。

## 保留的业务规则

周卡 7 元／7 天、月卡 14.99 元／30 天、年卡 129 元／365 天。均为单次购买、不自动续费；原时长、名额与退款规则保留。月／年促销数据为 `promotion.endsAt=null`。

新月／年订单使用 v4 快照，报价有效期仍为 10 分钟；过期报价须由用户重新确认。旧 v1／v2／v3 订单继续按冻结金额与原规则恢复，旧 v3 截止日期仅用于历史凭证校验。签名使用实际金额，不传 `activitySellingPrice`。详见 [支付配置说明](VIRTUAL_PAYMENT_SETUP.md)。

通知体验每条消耗 1 次签到／任务额度，会员同样扣次；明确失败自动退回，结果未知暂不退款且不重复发送。正式库存提醒仍需有效会员、有效关注及微信授权。界面不承诺送达、横幅或锁屏提醒。
