# 1.0.1 发布清理版：移除功能验收

更新：2026-09-15。本次是 1.0.1 前端发布清理，后端会员兑换接口维持已部署的 1.0.1，不需要重新部署云函数。

原版本的入口仅在 develop 显示；trial/release 无法开启模拟，但验收页仍被注册和打包，直接打开旧路径会显示仅开发版可用的提示。本次从微信上传根目录 `miniprogram/` 移除页面四件套、路由、所有入口与模拟执行分支。现在开发、体验、正式版本都使用真实账号和真实云函数。

「我的 → 会员 → 兑换码开通」保留，活动码和领取规则保持不变；付费购买仍暂未开放。模拟开关和缓存即使残留，也不会影响账号、兑换、查询或微信授权；真实业务缓存、请求恢复 ID、会员和提醒记录保留。原模拟引擎只留在 `tests/helpers/` 作为本地回归样例，不进入微信上传目录。

本轮全量自动化 224 项通过，150 个离线排版场景无检测到的缺字、溢出或裁切。发布预检新增验收页面和模拟模块不存在的检查。详细日志与原生界面核对记录位于 `evidence/verification/1.0.1-release-cleanup/`。

请从当前原工程编译上传，或使用带“发布清理版”名称的新源码包；早先备份包保留其历史状态。此次没有提交微信审核或发布操作。
