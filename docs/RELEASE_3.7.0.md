# 果小哨 v3.7.0 发布说明

2026-11-12，微信开发者工具已成功上传 3.7.0 开发版，包体 1,117,600 字节。候选源码已同步，正式版尚未提审或发布。[GitHub #9](https://github.com/kirrrto/guoxiaoshao/pull/9)

## 用户更新

- 查询结果按门店展示货号对应的取货状态与观测时间。切换配置或门店后，保留的上次结果标明自己的目标。
- 我的小哨突出下一次计划提醒和库存关注。授权充足时可以先看库存，需要处理授权时可以直接进入。
- 历史记录按实际时间排列，同一秒的多家门店各自显示状态。会员身份、果哨标志、有效期和名额共用账户卡的底色。到货和断货的授权次数分别显示。[页面前后对照与验收](../evidence/design/3.7.0/README.md)

## 查询、账号和库存可靠性

- 用完最后一次查询额度时，如果响应在网络中断时丢失，恢复同一账号、配置和门店可继续上次请求。回归核对了冷启动、换门店、换账号与原请求号，恢复路径只扣一次。
- 切换账号时分别维护余额和额度版本，迟到的旧响应不会盖掉新账号的余额。
- 时间戳超前、过期、顺序矛盾的观测按待确认状态展示。采集状态缺失时，查询、历史和账户页面仍可打开并说明当前状态。[功能验收与回归范围](../evidence/verification/3.7.0/functional-reliability.json)
