# 果小哨 v2.0.0 发布说明

记录日期：2026-10-11（北京时间）。状态：**本地候选，未部署云函数、未上传微信版本、未提审或正式发布**。用户提供的规划书作为参考，本轮按现有实现与实际使用路径做增量取舍。

## 本版解决的问题

- 查询结果提供明确下一步：近期有效可取货观测优先提供官方购买信息；已知暂无货且后台正常才解释持续关注；未知、过期、失败优先恢复原查询。新品权限受限明确说明，受限旧快照不展示库存证据。
- 会员开通保留真实配置和门店，按服务端数据显示时长与金额。月卡、年卡均直接可选，展示标准价、优惠实付、日均价格和截止时间；购买记录与攻略提供直接入口。付款须知仍需明确同意；确认期间账户、目标、价格或条款变化时必须重新确认。
- 账户隔离的待关注意向保留 24 小时；重启可恢复，过期或目录变化需重新确认。付款成功后主动继续保存关注，再主动授权微信提醒。会员、保存成功、提醒就绪、有效观测分别呈现，不把付款当作已经开始提醒。
- 启动阶段让出首屏渲染机会，目录及页面展示缓存单次异步读取，底部导航保留节点和固定图标资源。支付、授权与扣次恢复编号继续使用可靠持久化。
- 库存缓存须经过当前账户权限核验后展示，此保护不受体验开关影响。新缓存绑定账户；无归属的旧缓存、错号缓存保留配置与门店，库存需主动重新查询。慢连接、断网和换号后的迟到响应不能提前显示旧库存或衍生推荐。
- 支付受阻提供稳定诊断码；未知 iOS 收银台失败提示查询原订单，不再统一归因 Apple ID 地区。原订单恢复与服务端核实权益继续保留。
- 通知测试的未完成意向和异步回调绑定发起账户，服务端核对请求的预期账户与可信身份。错配时不保存授权、不扣次数、不发送消息；原编号与原账户恢复、幂等发送继续保留。此项来自对 source map 与本地页面差异的进一步复现，见 [映射定位复核](SOURCEMAP_REVIEW_2.0.0.md)。
- 新增开屏发售日历与独立选购攻略。首屏渲染完成后异步读取展示偏好，每个发售版本每天最多一次，可勾选本次发售不再提醒；分享配置和朋友圈单页跳过，不打断编辑或查询。iPhone Duo 开屏展示到 10 月 23 日结束，随后仍可在攻略中查看至登记的展示期限。选购准备、开启小哨、收到提醒、完成取货分四步，另有常见问题。日历日期不会改变目录 `comingSoon`/`supported`，也不会自动开启采集或监测。
- 界面收口：查询页将「发售日历与选购攻略」置顶并使用主题绿重点色；开屏日历改为 iPhone Duo 海报（主标题大于日期数字，圆形关闭按钮），并加入预购／发售倒计时（每分钟刷新）；攻略日历展示 iPhone Duo 商品图（图失败自动隐藏）；修复「我的」会员标题行「已开通／购买记录」挤压换行。
- 增长事件最少化批量采集，后台区分真实付款、赠送兑换、未知旧订单、隐藏记录与已核实退款；首次有效意向按成熟 7×24 小时队列统计。来源、账务口径及局限见 [增长说明](GROWTH_2.0.0.md)。

## 保留的业务规则

用户于本轮明确调整价格：月卡标准 30 元、限时 14.99 元（30 天）；年卡标准 360 元、限时 129 元（365 天）。截止时间为 **2026-11-30 23:59 北京时间**，服务端在 2026-12-01 00:00 自动切换标准价。周卡仍为 7 元/7 天。优惠通过微信 `goodsPrice` 标准价与 `activitySellingPrice` 实际优惠价签名，已有 19.90/200 元历史订单的金额、核实和退款保持原快照；过期且未签发的报价需重新确认，已签发订单只核实原单。

周卡 3×3、真实付费长期权益 4×4；到期/超限的配置保留并停止对应监测。免费查询、历史、任务奖励、幂等扣次与返还、订阅次数、免打扰和订单核实规则沿用。没有新增免费真实到货提醒、自动续费、保留库存或代购能力。

## 本地验证

最终测试及源码/发布检查记录在 `evidence/verification/2.0.0/`；以最终的 `verification-summary.json` 为准，早期 `first-regression.tap` 仅记录修复前检查，不是最终结论。离线布局预览从真实 WXML/WXSS/页面 JS 生成，数据为模拟，不能证明微信真机表现或付款/消息送达。

## 发布前配置与验收

新开关位于服务端 `features`：`contextualCheckout`、`resultNextAction`、`activationJourney`、`targetEvidence`、`growthEvents`、`experimentAssignments`、`launchGuide`。**默认全部 false**，本地离线预览显式启用。运营项目可读取并调整；没有在本轮修改生产开关。

本轮按维护者新增要求接入的开屏日历、独立攻略和服务端促销定价不依赖上述实验开关；`launchGuide` 仍只控制原查询结果旁的新品准备卡。开屏不调用库存、支付或通知接口，偏好是设备本地展示缓存，不作会员权益依据。

查看效果先打开 `tmp/ui-preview-v2/index.html`；这是可切换场景和宽度的离线预览，不连接生产数据。微信开发者工具导入本仓库根目录后，新体验需在指定的测试运行环境显式配置 `features`。`config/v2-preview.runtime-patch.json` 提供仅打开界面功能、关闭增长采集与实验的示例，应合并相应字段，不能整份替换既有业务配置。界面检查的范围、复现命令及截图说明见 [界面验证记录](UI_2.0.0.md)。

1. 部署前备份代码和现有配置，确认真实运行版本；当前 E 盘目录没有 Git 元数据，不能声称对应某个已验证提交。
2. 按 `config/database-deployment-plan.json` 建立新增分析集合、索引及服务端权限；确认留存任务。按 [支付配置说明](VIRTUAL_PAYMENT_SETUP.md) 核对或发布标准价为 3000/36000 分的商户商品及映射，不能用旧截图证明新价已发布。先部署 `gxs_api` 与重新生成的 `gxs_monitor`，再上传消费者页面，核对云端配置未被默认值覆盖。消费者与管理员 UI 分开上传。
3. 在开发版本开启待验收功能，验证目标→购买→付款核实→关注保存→主动授权→实际观测；覆盖关闭重进、换号、断网、目录变化、超限与到期。完成 iOS/Android/桌面、窄屏/大字体/折叠展开/深色的设备验收。
4. 真实付款、退款、通知需明确授权后执行。既有 iOS 15/微信 8.0.68 前置门槛保留，公开官方文档未能读取，不代表本轮已经完成平台规则与真机兼容核验。
5. 灰度前核对准确退款政策、真实支付/监测配置、目标新鲜度和高峰容量。300 人同时查询、全覆盖周期和有货复查指标仍为待验证要求，`productionAcceptancePassed` 保持 false。
6. 可观测性验证后再启用实验分桶；A/A、样本量、成熟窗口及真实效果都需要上线数据，不能将本地行为测试写成转化提升。

## 回退

优先关闭新体验/事件开关，保留原购买入口、原订单核实及所有会员/关注/授权账本。开关回退不清待支付订单、不取消合法监测、不删除已经发放的权益。不要回滚数据库快照。分析集合不可被客户端直接写入，关闭采集不影响业务接口。

改动前代码备份为 `tmp/v2-input/baseline-1.6.1.zip`；恢复时先解压到一个新目录核对，不覆盖正在运行的生产账本。构建源差异清单及候选包哈希记录在验收目录。
