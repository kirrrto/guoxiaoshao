## 维护者上线验收

1. 部署本版 `gxs_api` 和 `gxs_monitor`，下载云函数核对实际代码。通过可信云端运维调用 `admin.seedCatalog` 发布随包目录，再回读 `catalog.get`。预期 383 个配置、49 家门店，一代 HomePod mini 为 0 个，HomePod mini 2 为 5 个。各地区开关及现网共享鉴权沿用原配置。
2. 在体验版选取一个仍在售的配置及一条旧关注，复核选型、历史观测和删除。验证退役目标不产生新轮询或微信提醒，从上个版本升级时没有再出现已退役机型。
3. 如需发放单账号年卡，在 `gxs_api` 的云端环境变量 `GXS_OWNER_ANNUAL_GIFT_USER_KEY` 填写受赠人的完整消费端 `appid:openid`。由可信云端运维调用下方事件。调用成功后再次执行同一事件，应返回 `already_granted`，到期时间保持一致。回读 `membership.planId` 为 `member_365d`，`membership.limits` 中的 `maxFollows` 和 `maxStoresPerFollow` 均为 5。已有有效年卡的账号返回 `already_annual`。微信订阅授权仍由账号本人完成。

   ```json
   {"action":"admin.grantOwnerAnnualPass","payload":{}}
   ```

4. 上传本包后，按当前指纹在微信后台复测未使用组件、原生底栏首切、商品图体积和图片格式，再由维护者提审发布。三站的监测及中英文真机收信沿用 [3.8.0 验收步骤](RELEASE_3.8.0.md)。

单账号年卡只发一次，时长 365 天，优先消耗。原有普通会员时长随后继续使用。赠送以独立的零元记录入账，既有支付交易及退款归属保持原样。个人账号标识仅在云端配置中保存。

## 回退

保留部署前的两份业务云函数、旧目录和发放记录。需要回退时，先停止受影响轮询与发送，成对恢复匹配的业务代码和目录。恢复旧目录会重新带回失效货号，重新开放前需核对。已发放的会员时长必须保留原有账本，不要用旧备份覆盖发放后的用户数据。
