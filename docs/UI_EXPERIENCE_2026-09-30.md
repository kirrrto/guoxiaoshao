## 设计取舍

参考《果小哨 UI 体验升级项目规划书 v1.0》，以“选配置 → 看门店观测 → 关注变化 → 接收提醒”为主线。优先减少常驻长表单与重复说明，避免再增加一层“购物计划”概念。

- 查询、历史、小哨复用原生底部配置面板。页面显示已保存条件，面板承载本次草稿；明确保存后才改变条件，打开面板不会查询、扣次数或写关注。
- 查询首屏保留配置、门店、主查询动作和直接关注路径。规则可展开，收费、免费体验和新品限制仍有明确提示。旧查询结果继续标记原配置与时间。
- 小哨页以具体关注卡为主。健康状态正常时弱化技术细节，需要处理的异常给出对应动作；授权不足时提前显示授权入口。到货和断货保留同一个按钮、分别显示余额。
- 历史页先显示条件、结果与记录，最近浏览作为恢复入口放到次级位置。无记录、未知和缺少采样证据继续明确区分。
- 我的页突出有效期、价格、配置名额和微信授权条件；已有会员的续费入口改为次要动作。未完成订单、查询支付结果、继续支付、放弃订单、兑换和退款记录保留。
- 使用中性浅背景、实体白卡片和绿色主动作，深色模式使用对应的高对比颜色。保留现有哨子标识与透明浮动导航。黑金仅用于会员标识。
- 根据实际使用反馈，展开、收起和跳转入口采用统一的轻量按钮或整行控件，以底色、边界和方向标识提供可点击感；主要操作保持更高视觉权重。
- 查询结果改为左侧商品缩略图、右侧商品名称和快照相关信息。去掉大幅居中图片造成的空白，长名称和小屏宽度允许自然换行。
- 「我的」增加更新公告入口，集中展示已登记的各版本变化；记录日期不等同于发布日期，未知小结保留待补充，开发与部署状态留在发布文档。
- 修改按钮移到门店摘要旁，不与商品标题争抢空间；已核验的 iPhone 18 Pro/Max 图片补偿透明边距，本体占图框高度约 92%，其他品类保持完整等比展示。
- 查询与提醒规则栏和上方按钮等宽；提醒服务详情展开后平滑滚动到内容，收起、连续点击或离开页面会取消迟到的滚动。

本轮未增加多颜色计划、门店矩阵、连续库存时间轴或新提醒偏好。它们涉及持久化、额度、历史覆盖及兼容设计，不能只靠前端并排展示就当作完整功能。

## 一起修复的交互问题

- 旧提醒“买到了”只凭 `followId` 暂停，可能误停后来编辑的新配置。新任务保存 SKU、完整门店集合及关注更新时间，反馈和条件暂停在同一事务内完成；缺少可靠快照的旧提醒只记录反馈。
- 同一毫秒的连续编辑也递增关注更新时间，避免“改走再改回”被旧提醒误认为原目标。
- 暂停、删除或保存已经成功时，后续列表读取失败只提示刷新失败，不再把已确认写入说成失败。
- 自动刷新保持已有关注顺序及展开状态，编辑一项不再将卡片挪到列表末尾。
- 配置面板与兑换弹窗占用独立导航隐藏状态，收起键盘不会使底部导航重新出现；导航延迟挂载也读取当前弹层状态。
- 失效或损坏的缓存门店保持待核对状态，阻止按错误条件继续查询；不会悄悄转成全部门店。
- 保存同步读取最后一次选择；退出脏草稿要求明确放弃，保存中阻止重复提交与退出。系统返回使用原生 `page-container`，平台交互仍需真机验收。

本轮没有调整价格、支付开关、会员额度、订阅额度、检测频率或上游预算；没有迁移或修改生产数据。

本地源码、自动回归、官方 WXML/WXSS 编译、浏览器布局测量分别提供不同证据，均不能证明 iOS/Android 真机体验或云端已上线。仍需真机检查配置面板的软键盘、系统返回、槽位组件取值、放大字体和弱网恢复，以及真实支付和提醒链路。

发布这批改动时，旧提醒保护需要更新后的 `gxs_api` 和 `gxs_monitor`；monitor 由 `node tools/build-monitor.mjs` 生成，依赖闭包为 30 文件。先部署这两个兼容服务再上传前端，不需要迁移数据库。`cloudbase_auth` 仅同步包版本、未改鉴权逻辑；如果要求云端三个函数的部署版本均为 1.5.0，可一并部署并核对。仅上传前端不能使后端安全修复生效。

回退界面可恢复上一前端；建议保留新的后端条件校验，旧客户端调用仍兼容。已经记录的反馈与授权账本不做客户端回滚。

## 本地复现

```powershell
npm test
npm run check
node tools/build-monitor.mjs --check
node tools/release/check.mjs
node tools/ui-preview/build.mjs --out output/ux-r1/pages
node tools/ui-preview/build.mjs --sheets-only --out output/ux-r1/sheets
node tools/ui-preview/check-layout.mjs output/ux-r1/pages
node tools/ui-preview/check-layout.mjs output/ux-r1/pages --dark
node tools/ui-preview/check-layout.mjs output/ux-r1/sheets
node tools/ui-preview/check-layout.mjs output/ux-r1/sheets --dark
node tools/ui-preview/check-theme-colors.mjs output/ux-r1/pages output/ux-r1
node tools/ui-preview/check-theme-colors.mjs output/ux-r1/pages output/ux-r1 --dark
```

预览可加 `--remote-images` 读取目录映射的商品图片；默认完全离线。`--sheets-only` 覆盖三个入口、常规编辑、键盘占位、长文本和保存状态，键盘高度为模拟值。
