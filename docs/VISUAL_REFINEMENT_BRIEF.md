## 2. 为什么现在「不够高级」——逐条诊断

对照截图，问题集中在 7 点。高级感的本质是**克制 + 秩序 + 细节**，现状三者都差一口气。

### 2.1 绿色用得太多、太满
- 每页 1–3 个整宽绿色实心按钮，加上绿色状态文字、绿色标题（「1 家门店有可取货观测」）、绿色图标，绿色占屏面积约 8–12%。
- 高级界面的强调色通常 ≤ 3–5% 面积，靠中性色撑场。绿色越少，出现时越有分量。

### 2.2 所有东西都一样重
- 卡片标题、区块标题、按钮文字字号接近（28–34rpx），字重都是 600，缺少「一眼先看哪里」的落差。
- 右上角「刷新状态 / 数据说明 / 查询库存 / 管理到期事项 / 修改 / 购买记录」全是同一种灰胶囊，看起来像同一级别的东西在争抢。

### 2.3 卡片套卡片、边界太多
- 页面底色 → 白卡 → 灰色分组框 → 灰胶囊按钮，四层表面叠在一起，显得拥挤、廉价。
- 高级界面倾向于：**一层卡片 + 细分隔线 + 留白**，而不是更多框。

### 2.4 说明小字太碎
- 「按北京时间安排；微信受理不代表实际收到」「观测不锁库存，购买请在 Apple 官方渠道完成」「会员查询不扣次数」「会员购买暂不可用…」散落各卡。
- 灰色小字一多，画面就变「说明书」。要集中、分级，而不是删掉。

### 2.5 数字没有被当成主角
- 日期、时间、次数、名额是这个产品最核心的信息，但数字没有用等宽数字、没有统一的数字字号体系，时间轴里时间和门店名几乎同等权重。

### 2.6 商品图没有展示感
- 查询页商品图是小方块，关注/历史更小，底色白/灰不统一。商品是用户最在意的「主角」，现在像缩略图图标。

### 2.7 细节缺少打磨
- 圆角处处 32rpx，大卡、按钮、胶囊、图片圆角缺少层级关系（应「外大内小」）。
- 没有按压反馈的统一规范；深色模式卡面与背景明度差小，中性按钮几乎融进卡面。
- 页头不统一：查询/小哨有品牌图标，历史没有，我的直接是会员卡。

## 3. 设计方向：「安静的取货凭条」

一句话：**中性纸面 + 清晰排版 + 一处绿色**。参考对象（只学方法，不抄样式）：

- Apple Store App 的订单/取货详情页：大商品图、分组列表、少量强调色
- iOS「设置」/「钱包」的 inset grouped 列表：区块标题在卡片外，卡片内用细线分行
- 微信支付账单详情：大数字 + 小标签的对齐方式

三条原则：

1. **一屏一个主角**：每屏首屏只有 1 个绿色实心按钮；其余操作降级为中性按钮、文字链接或列表行。
2. **用排版而不是框来分层**：字号/字重/颜色/留白建立层级，减少嵌套背景框。
3. **数字是主角**：日期、时间、次数、名额统一使用数字字号体系和等宽数字。

## 4. 设计令牌升级（先改这里，所有页面复用）

在 `app.wxss` 的 `page {}` 和深色媒体查询中**新增或调整**以下变量，并同步到 DESIGN.md 前置 tokens。数值是建议起点，改完必须实测对比度。

### 4.1 字号体系（rpx，按 750 宽设计）

| 令牌 | 用途 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- | --- |
| `--fs-display` | 页面唯一大数字/大标题（日期、会员档位） | 60rpx | 600 | 1.15 |
| `--fs-title` | 页面标题 | 40rpx | 600 | 1.25 |
| `--fs-headline` | 卡片标题、商品名 | 34rpx | 600 | 1.3 |
| `--fs-body` | 正文、列表主文字 | 30rpx | 400 | 1.5 |
| `--fs-sub` | 列表副文字、门店地址 | 26rpx | 400 | 1.45 |
| `--fs-caption` | 说明、时间戳、标签 | max(12px, 24rpx) | 400/500 | 1.4 |
| `--fs-section` | 卡片外区块标题 | max(12px, 24rpx) | 500 | 1.4，颜色 `--text-3` |

规则：
- 一张卡片内最多出现 3 级字号；相邻两级至少差 4rpx。
- 600 字重只给 display/title/headline 和主按钮；其余 400 或 500。
- 所有数字（日期、时间、次数、名额、价格、货号）加 `font-variant-numeric: tabular-nums;`，货号保留现有等宽样式。

### 4.2 颜色

浅色：

| 令牌 | 建议值 | 说明 |
| --- | --- | --- |
| `--green-mist`（页面底） | `#F4F4F2` | 去掉一点绿色倾向，更像纸面 |
| `--card` | `#FFFFFF` | 不变 |
| `--surface-soft` | `#F6F6F4` | 仅用于卡片内必须分组时，尽量少用 |
| `--line` | `#ECECEA` | 细线，用 1px（`1rpx` 在部分机型会消失，用 `0.5px` + 兼容方案或 `1px`） |
| `--text` | `#111412` | |
| `--text-2` | `#5B605D` | 副文字 |
| `--text-3` | `#6E736F` | 说明/标签，必须 ≥ 4.5:1 |
| `--control-fill` | `#F0F0EE` | 中性按钮 |
| `--control-pressed` | `#E6E6E3` | |
| `--accent-text` | `#007A49` | 绿色文字（有货等），只用于状态，不用于标题 |

深色：

| 令牌 | 建议值 | 说明 |
| --- | --- | --- |
| `--green-mist` | `#0B0D0C` | 更深的底，拉开与卡面的差 |
| `--card` | `#171A18` | |
| `--card-elevated` | `#1F2320` | 抽屉、弹层、选中行 |
| `--control-fill` | `rgba(255,255,255,0.09)` | 比现在稍亮，避免融进卡面 |
| `--control-pressed` | `rgba(255,255,255,0.14)` | |
| `--line` | `rgba(255,255,255,0.07)` | |

颜色使用规则：
- 绿色只出现在：主按钮、选中态、有货/成功状态的圆点或文字、tab 选中。**标题、汇总句、图标装饰不用绿色。**
- 警示 `--warn`、错误 `--bad` 只给真实异常，不给普通提示。
- 新增状态胶囊三档：
  - 正向（可取货、已安排）：`--green-soft` 底 + `--accent-text` 字 + 实心圆点
  - 中性（暂无供应、已暂停）：`--control-fill` 底 + `--text-2` 字 + 空心圆点
  - 待确认/陈旧/未知：透明底 + `--warn` 字 + 虚线圆点或「!」图形

### 4.3 圆角（外大内小）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-card` | 28rpx | 页面卡片 |
| `--radius-inner` | 20rpx | 卡片内的图片容器、内嵌分组 |
| `--radius-action` | 22rpx | 主/中性按钮 |
| `--radius-chip` | 999rpx | 状态胶囊、日期切换 |

规则：内层圆角 ≈ 外层圆角 − 内边距的一部分，绝不出现内层比外层更圆。

### 4.4 间距（8 的倍数节奏）

| 令牌 | 值 |
| --- | --- |
| `--space-page` | 32rpx（页面左右边距，保持） |
| `--space-card` | 32rpx（卡片内边距，原 30rpx 统一到 32） |
| `--space-section` | 48rpx（卡片与卡片之间；原 26rpx 太紧，是「挤」的主要来源） |
| `--space-row` | 28rpx（列表行上下内边距） |
| `--space-stack` | 8 / 16 / 24rpx（同组元素的紧凑间距） |

规则：**组内紧、组间松**。同一个信息组内用 8–16rpx，不同组之间至少 32rpx，卡片之间 40–48rpx。

### 4.5 阴影与层次

- 浅色卡片：`0 1px 2px rgba(17,20,18,0.04), 0 8px 24px rgba(17,20,18,0.05)`，不要更重。
- 深色：不用阴影，只靠 `--card` 与 `--green-mist` 的明度差。
- 抽屉、弹层用 `--card-elevated` + 遮罩 `rgba(0,0,0,0.4)`。

### 4.6 动效

- 时长：按压 120ms，展开/收起 200ms，抽屉 260ms；曲线 `cubic-bezier(0.2, 0, 0, 1)`。
- 按压反馈：按钮和可点击行统一 `hover-class`，背景切到 `--control-pressed`，主按钮可加 `transform: scale(0.98)`。
- 尊重减少动态：`prefers-reduced-motion` 下直接切换状态。
- 不加装饰性动画、渐变流光、骨架以外的循环动画。

### 4.7 点缀质感：渐变与毛玻璃（仅限下列 4 处）

维护者已确认：允许以「点缀」方式使用渐变和毛玻璃，**只用在下表 4 个位置**，其余所有正文卡片、状态胶囊、按钮、列表行保持不透明纯色。这是对 DESIGN.md「Elevation & Depth」中“不依赖背景模糊、装饰性渐变”的有限例外，交付时须同步修订 DESIGN.md 该节，写明这 4 处例外和降级规则。

| 位置 | 做法 | 建议参数 |
| --- | --- | --- |
| 我的页会员卡 | 同色相线性渐变，体现会员身份；普通用户保持纯白卡 | 浅色年卡：`linear-gradient(135deg, #FFFFFF 0%, #F7F3EA 100%)`；深色年卡：`linear-gradient(135deg, #1F2320 0%, #241F17 100%)`；周/月卡用更淡的绿灰同法（明度差 ≤ 6%）。卡内文字对比度按渐变最浅处和最深处两端分别实测 |
| 页面顶部吸顶区 | 滚动超过页头后出现半透明 + 模糊背景，类似 iOS 导航栏 | 浅色 `rgba(244,244,242,0.82)`，深色 `rgba(11,13,12,0.82)`；`backdrop-filter: saturate(180%) blur(20px)` 并加 `-webkit-` 前缀；底部 1px `--line` |
| 商品图底板 | 极淡径向渐变，模拟展台打光 | 浅色 `radial-gradient(circle at 50% 40%, #FFFFFF 0%, #F2F2F0 100%)`；深色沿用 `--image-tile` 基色做同样 5% 明度差 |
| 抽屉 / 弹层遮罩 | 遮罩轻微模糊，抽屉本体不透明 | 遮罩 `rgba(0,0,0,0.36)` + `backdrop-filter: blur(8px)`；抽屉面板用 `--card-elevated` 纯色 |

强制规则：

1. **必须有纯色降级。** 不支持 `backdrop-filter` 的机型或基础库，吸顶区退回不透明 `--green-mist`，遮罩退回 `rgba(0,0,0,0.45)`。用 `@supports (backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))` 包裹模糊样式，默认写纯色。
2. **文字永远不放在模糊层上直接读数。** 吸顶区只放页面标题和一个工具入口；库存状态、时间、次数等数据不得出现在半透明表面上。
3. **对比度实测。** 渐变卡片在浅深色下，最浅、最深两个取色点都要满足正文 ≥ 4.5:1；吸顶区标题在其下方是白卡和深色内容两种情况下都要测。
4. **不做动画渐变**、流光、呼吸效果；不做整页渐变背景；不把毛玻璃用在正文卡片上。
5. **性能**：模糊只用于固定位置的单层元素（吸顶区、遮罩），不要用在会随列表滚动的元素上；安卓真机需单独验证滚动流畅度，未验证要在交付中写明。
6. 减少动态开启时，吸顶区直接显示或隐藏，没有过渡动画。

## 5. 组件规范（在 common.wxss 建立，四页复用）

### 5.1 按钮三级

| 级别 | 外观 | 高度 | 每屏数量 |
| --- | --- | --- | --- |
| 主按钮 `.btn-primary` | 绿底 + 深墨字，600 | 96rpx | 首屏最多 1 个 |
| 中性按钮 `.btn-neutral` | `--control-fill` 底 + `--text` 字，500 | 80rpx | 不限，但并排最多 2 个 |
| 文字按钮 `.btn-text` | 无底，`--text` 或 `--accent-text` 字 + `›` | ≥ 44px 点击区 | 用于卡片标题右侧入口 |

- 主按钮切换规则要写在页面 JS 的数据里，按状态决定谁是主按钮，例如：查询页无结果时主按钮=「立即查询」，有可取货观测时主按钮=「查看下单指引」，「立即查询」降为中性。
- 删除「右上角灰胶囊」这种第四种样式，统一归到上面三级。

### 5.2 区块结构：inset grouped

```
区块标题（卡片外，--fs-section，--text-3）        右侧文字入口 ›
┌──────────────────────────────────────────┐
│ 主信息行                                  │
│ ──────────────────────────────── 细线     │
│ 列表行：左主文字 / 副文字      右值 或 ›   │
│ ──────────────────────────────── 细线     │
│ 列表行                                     │
└──────────────────────────────────────────┘
```

- 「到期提醒」「苹果库存」「微信提醒」「会员权益」等原本写在卡片内的标题，移到卡片外作区块标题；卡片内直接从内容开始。
- 卡片内不再嵌套灰色分组框，改用细线分行。

### 5.3 列表行 `.row`

- 最小高度 96rpx；左侧主文字 `--fs-body` + 副文字 `--fs-sub`；右侧数值右对齐（等宽数字）或 `›`。
- 可点击整行，按压变 `--control-pressed`；有可访问名称。
- 「展开」「查看」类折叠入口统一用此组件，右侧 `›` 或旋转箭头（200ms）。

### 5.4 数据块 `.stat`

- 用于「已保存关注 1/5」「每个配置 5 家门店」「到货提醒 12 次」「断货提醒 8 次」。
- 上方 `--fs-caption` 标签，下方 `--fs-display` 或 48rpx 数字 + 26rpx 单位（单位颜色 `--text-2`），数字与单位基线对齐。
- 两列网格，中间 1px 竖线或 32rpx 间距，左右对齐一致。

### 5.5 商品展示 `.product`

- 查询页（主角）：商品图容器 176×176rpx，`--radius-inner`，底色 `--image-tile`（浅色改为 `#F6F6F4`，深色保持 `#DCE1DE`），图片 `mode="aspectFit"`，四周 16rpx 留白。右侧：商品名 `--fs-headline`，规格 `--fs-sub`，SKU `--fs-caption` 等宽。
- 关注/历史（列表）：容器 112×112rpx，同一底色与圆角。
- 三处容器底色、圆角、留白完全一致。

### 5.6 状态胶囊 `.chip`

- 高 44rpx，左右内边距 16rpx，字号 `--fs-caption` 500，圆角 999rpx，左侧 12rpx 圆点。三档样式见 4.2。

### 5.7 说明文字 `.note`

- 每张卡片最多 1 行说明，放卡片底部，`--fs-caption` + `--text-3`。
- 超过 1 条的规则说明，合并进页面底部一个「规则与说明」折叠行（`.row`），展开后逐条列出。**所有原有事实必须能在这里找到。**

### 5.8 页头 `.page-header`

- 四页统一：左侧页面标题 `--fs-title`，可选左侧 48rpx 品牌图标（四页要么都有、要么只在查询页有，二选一并在 DESIGN.md 写明）；右侧最多 1 个工具入口（图标按钮或文字按钮）。
- 页头与第一张卡片间距 24rpx。

## 6. 逐页改造方案
