## 本地验证

1. 根目录运行 `npm ci` 安装精确锁定的构建依赖。
2. 三个云函数分别运行 `npm ci`，恢复精确锁定的 SDK 依赖。
3. 修改共享后端后运行 `node tools/build-monitor.mjs`。
4. 运行 `node tools/build-monitor.mjs --check`、`npm test`、`npm run check`、`node tools/release/check.mjs`。
5. 微信开发者工具导入根项目，用户上传目录仍为 `miniprogram/`。运营项目另行导入 `tools/admin-miniprogram/`，不要作为用户版上传。
