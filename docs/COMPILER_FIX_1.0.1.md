# 1.0.1 编译修复版：Babel 辅助模块缺失

更新：2026-09-15。本次是发布清理版后的前端兼容修复，云函数继续使用已部署的 1.0.1。

用户日志的阻断错误为 `@babel/runtime/helpers/arrayWithHoles.js` 未定义，查询页初始化因此失败，并伴随 `wx://not-found`。`[Perf] App.initCloud took 85ms` 等为性能提示，不是这次白屏的主错误。

四个页面有五处数组解构，会经增强编译生成 `slicedToArray`，再依赖 `arrayWithHoles`。本版改为等价的数组索引读取，保留 Promise.all 并发和免打扰时间计算。没有关闭 ES6/增强编译，没有安装新的业务 npm 依赖，没有恢复验收页面。

实际开发者工具在修改后恢复首页，并重新执行“工具 → 编译”（Ctrl+R）检查。页面与日志核对、官方 Babel 转译对比及完整测试结果保存在 `evidence/verification/1.0.1-compiler-fix/`。源码直接执行测试不能替代微信编译验收。

本次没有清除业务数据或缓存，没有开启 CLI 服务端口，没有修改支付、会员规则和云函数。前端辅助函数缺失已通过语法兼容修复规避；不能仅据现有日志断言是单一缓存开关或特定工具设置造成的。
