# 果小哨 v3.8.2 发布说明

指定管理员可直接验证新品库存查询和关注，无需购买或续费。「我的」显示测试身份和可用名额。上线需要维护者部署两个业务云函数，然后用同一账号在微信体验版核对页面、查询和提醒。

本次消费端源码指纹为 `sha256:022c8b4db36759b4fbd25ffc3ea7c837bc15bb80ea4429e5909a5d9e4dfc5004`，供上传后关联微信质检报告。

## 账号与权益

消费端最多可关注 5 个配置，每个配置最多选择 5 家门店。测试权限独立于原有会员时长。库存查询和「体验微信提醒」都免扣查询次数。微信订阅仍需本人授权，发送失败会按实际扣费结算。购买、退款和到账须通过支付流程单独验收。

云端现有管理员名单与两个业务函数的 `GXS_TEST_ADMIN_USER_KEY` 共同决定测试身份。变量使用完整的消费端账号，只在云端配置中保存。2026-11-23 已回读确认指定账号是唯一的管理员，两个函数都已绑定该账号。代码部署前，现网 3.8.1 仍按原会员权益运行。

地区查询、监测、通知仍分别受站点开关控制。现场核对时，日本、台湾、香港的三组公开开关均为关闭。大陆 3.8.1 目录已更新并回读，共有 383 个配置、49 家门店；第一代 HomePod mini 已退役，二代保留 5 种颜色。

## 本地验收

本版全量自动化测试 2,147 项通过。发布检查 66 项中有 65 项通过，剩余一项需要微信后台出具本包质检复测结果。

使用实际页面模板和样式离线渲染「我的」、查询、小哨、其他站点和通知体验页。中文、英文，320 和 1024 像素，以及浅色、深色共 40 个视图均无横向溢出；可点击按钮高度均达到 44 像素。「我的」展示测试身份和实际名额，隐藏续费与到期日期。此项验证使用测试数据。

撤销测试权限后，原来允许选择 5 家门店的未完成查询会按账号当前名额复核。用户在界面确认免扣次后，即使权限在提交前变更，也要重新确认费用。已完成的查询仍可查看原回执。

## 验收与回退

1. 由维护者部署本版 `gxs_api`、`gxs_monitor`，回读两份运行代码并确认绑定仍匹配。通过体验版用指定账号进入「我的」，核对身份和名额。在同一台设备切换到普通账号，复核查询扣次、关注资格和购买页。
2. 用指定账号保存一条关注并在微信中授权。分别核对定时采集、库存状态变化、提醒送达及点击后的落点。
3. 需要停止测试时，清除两个业务函数上的测试变量，保留其余环境变量，重新读取账号权限。如果需要同时撤销运营管理权，由云端运维通过受保护的管理员名单更新完成。原会员期限、账本及订单继续有效。
4. 微信质检复测、真机收信、上传提审与发布由维护者完成。
